<threat_model>
ASVS level: L1. Any unresolved high-severity threat blocks dependent live action.

## Trust Boundaries

| Boundary | Description |
|---|---|
| Live state → off-host restic → blank restore | Sensitive coherent state crosses encryption and destructive recovery boundary. |
| Internet → every public address → nftables/Caddy | Unknown dual-stack traffic crosses final public exposure boundary. |
| Public/private routes → one Pyramid backend | Route precedence must prevent privileged public access. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-04-01 | Tampering / Denial | backup/restore/rollback | high | mitigate | Quiesced matching generation, restic check, blank marked target, live-path refusal, failed-state preservation, protocol acceptance. |
| T-04-02 | Information Disclosure | backup credentials/state | high | mitigate | Protected credential file, no argv/unit/Git/payload value, encrypted off-host target, private captures. |
| T-04-03 | Elevation of Privilege | public routes/ports | high | mitigate | Pin-derived route matrix, fixed denial, all-address full TCP scans, Caddy-only 80/443. |
| T-04-04 | Elevation of Privilege | IPv6/secondary address drift | high | mitigate | Fresh host/provider/A+AAAA reconciliation before/after scan; full rescan after any change. |
| T-04-05 | Denial of Service | public cutover/firewall | high | mitigate | Concurrent private recovery path, rollback on mismatch, ingress enabled last. |
| T-04-06 | Tampering | discard/redeploy | high | mitigate | Advance notice, best-effort export, marked target, retention-approved preservation, exact-lock redeploy. |
| T-04-07 | Spoofing / Repudiation | external scan vantage | high | mitigate | Protected authorized runner handoff, fresh family route/identity/tool validation, full-port scope, and fail-closed cutover. |
